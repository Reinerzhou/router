The content-affinity switch is process-wide and disabled by default. Enable it before startup
when complete rendering configuration and message boundaries should determine cache affinity.
Without it, official token/session cache-routing behavior is retained. This is an approximate
placement hint, not engine KV ownership. Request bodies are not rewritten by this switch.

Native observability remains opt-in; see [configuration](native_observability.md).
Neither an Ascend deployment nor backend Python source has been modified. Backend patch necessity
and compatibility with real H200/910C deployments require separate verification.
